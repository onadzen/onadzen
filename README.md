# Ronald Nuñez

WordPress and Astro developer. I work on the technical side of websites: performance,
technical SEO, and moving sites off legacy CMSs without losing rankings.

## What I do

- WordPress builds and takeovers, including Elementor and Beaver Builder stacks
- Astro and Tailwind sites, built to ship through Git
- Core Web Vitals work, measured before and after rather than guessed at
- Migrations with URL parity, verified per page against a manifest
- Technical SEO: canonicals, structured data, indexing rules, sitemaps
